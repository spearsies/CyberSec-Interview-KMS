# Cyber Kill Chain

## Overview
Lockheed Martin's 7-stage model of an intrusion. Disrupting any single link breaks the attack.

## The stages
1. Reconnaissance
2. Weaponization
3. Delivery
4. Exploitation
5. Installation
6. Command & Control
7. Actions on Objectives

Linear and attacker-centric — contrast with ATT&CK, which is a non-linear matrix of behaviors. Useful for framing *where* a control or detection sits.
