# MITRE ATT&CK

## Overview
A globally accessible knowledge base of adversary **tactics** (the goal — e.g. Persistence, Lateral Movement) and **techniques** (the how — e.g. T1059 Command and Scripting Interpreter), built from real-world observations. It's the common language for describing, detecting, and mapping attacker behavior.

## Key details
- **Tactics** = the columns (the adversary's objectives); **techniques / sub-techniques** = the methods, each with an ID like `T1059.001`.
- Matrices: Enterprise, Mobile, ICS.
- Uses: coverage mapping (Navigator heatmap), threat-intel tagging, purple teaming, gap analysis.
- Not exhaustive — weight techniques by relevance and likelihood.
