# ❓ Which cloud security frameworks and benchmarks would you reference?

## ✅ Quick Answer
Use **benchmarks** for hardening and **frameworks** for governance: CIS Benchmarks give concrete, checkable config baselines; the provider's Well-Architected security pillar guides design; the CSA Cloud Controls Matrix maps controls; and NIST CSF / 800-53 and ISO 27001 frame the overall program. Map controls once and satisfy many.

## 🗣️ Talking points
- CIS Benchmarks: prescriptive and tool-checkable (Prowler, Config, Defender).
- AWS/Azure Well-Architected security pillar for design decisions.
- CSA CCM + CAIQ for control mapping and vendor assessment.
- NIST CSF functions: Identify, Protect, Detect, Respond, Recover.
- ISO 27001 / SOC 2 for certification and attestation.
- Scope everything against the shared responsibility line.

## ⚠️ Follow-ups they'll hit you with
- Framework versus benchmark — what's the difference?
- How would you automate CIS benchmark checks?
